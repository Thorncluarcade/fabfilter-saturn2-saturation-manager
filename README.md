## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Save Saturn 2 configurations per instrument and saturation style |
| **Drive Notes** | Document drive amount and saturation character per preset |
| **Band Config** | Track multiband crossover and individual band settings per preset |
| **Mix Context** | Log which mix contexts each Saturn 2 preset is optimized for |
